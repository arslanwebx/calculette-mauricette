# 1. Project Mission

The project should become the best French online resource for:

- calculating working hours;
- using a Mauricette-style time calculator;
- calculating daily and weekly totals;
- adding and subtracting hours;
- deducting breaks;
- converting hours/minutes to decimal or centesimal time;
- understanding 35-hour and 39-hour schedules;
- estimating overtime when appropriate;
- understanding complementary hours for part-time work;
- calculating night/Sunday time where the user supplies the applicable rules;
- exporting or printing timesheets;
- using Excel or printable templates for working-time tracking.

The project is **not** intended to become a generic calculator directory during the initial growth phase.

The topical focus is:

> **Mauricette → heures de travail → temps de travail → conversion horaire → heures supplémentaires / complémentaires → related working-time pay calculations**

# 14. Calculator Math Rules

Arithmetic and legal interpretation must be separate.

## Basic time calculation

For a same-day interval:

```text
duration = end - start
```

For an overnight interval:

```text
if end < start:
    end = end + 24 hours
```

Then subtract valid breaks.

## Example

```text
Start: 21:00
End:   06:00
Total before breaks: 9h
```

The result must never become `-15h`.

## Decimal conversion

```text
decimal hours = hours + minutes / 60
```

Examples:

```text
7h15 = 7.25
7h30 = 7.50
7h45 = 7.75
8h06 = 8.10
```

Never convert minutes by putting them directly after the decimal point.

`7h30` is **not** `7.30` decimal hours.

# 15. Legal / Payroll Guardrails

French working-time law and payroll rules are time-sensitive and can depend on:

- collective agreements;
- employment contracts;
- working-time arrangements;
- sector;
- employee classification;
- exceptions;
- company agreements;
- specific scheduling systems.

Therefore:

## Never claim

> Every hour above 8 hours in one day is legally an overtime hour in France.

That is an oversimplification.

## Never hard-code without qualification

> All overtime is always paid +25% then +50%.

Collective agreements can modify applicable rates within the legal framework.

## Product wording

When the calculator estimates remuneration:

Use wording such as:

> **Estimation indicative**

and explain what rates were applied.

Allow the user to enter a custom rate where feasible.

## Rule

The time-duration calculator must remain mathematically correct even when the legal/payroll interpretation varies.

- [ ] Identify the search intent.
- [ ] Identify the reader's real outcome.

- [ ] For legal/payroll content, collect current primary French sources before drafting.

- a worked calculation;
- original calculator;
- formula;
- interactive example;
- original comparison;
- original reference table;
- downloadable spreadsheet;
- printable timesheet;
- edge-case explanation;
- decision tree;

# 19. Cannibalization Rules

Keyword cannibalization is one of the biggest avoidable risks in this project.

## Before creating any page

Search for:

- exact keyword;
- singular/plural;
- “calculette” vs “calculatrice”;
- “heure” vs “heures”;
- close semantic variants;
- current related H1s;
- existing titles;
- existing routes.

## Examples

Do not separately create:

```text
/calculette-mauricette/
/calculatrice-mauricette/
```

Do not separately create:

```text
/calcul-heures-de-travail/
/comment-calculer-les-heures-de-travail/
```

if both pages would satisfy the exact same user task.

In this plan those two intents are separated intentionally:

- `/calcul-heures-travail/` = interactive calculator/tool intent.
- `/comment-calculer-heures-travail/` = instructional guide intent.

Keep that distinction obvious.

## If overlap develops

Prefer:

1. merge weaker page into stronger page;
2. update internal links;
3. add 301 redirect if a URL is removed;
4. update sitemap;
5. update canonical;
6. preserve backlinks.

Do not leave multiple near-identical indexed pages and hope Google chooses correctly.
